## Featured Projects

### 🧠 [RAG Document Assistant](https://github.com/fizzahussain/Rag-Document-Assistant)
A local-first document assistant that combines document parsing, OCR, speech-to-text, semantic retrieval, vector search, and local LLMs. Built to explore how a complete RAG application works beyond simply calling an LLM API.

**Python · FastAPI · PostgreSQL · pgvector · Ollama · RAG · OCR · Whisper · Docker**

### 🔬 [Revival Lab](https://github.com/fizzahussain/Revival-Lab)
A research-oriented RAG project exploring semantic retrieval over a curated archive of historical ideas and solutions.

**Python · ChromaDB · LangChain · OpenAI · Gradio**

### 🎮 [UNO — 3 Player AI vs Human](https://github.com/fizzahussain/UNO-3Player-AIvsHuman)
A game AI project where I implemented and compared Minimax and Expectimax, including game-state evaluation, chance nodes, and search-depth trade-offs. The project also went through several rounds of debugging while turning the original simulation into a playable web version.

**Python · Minimax · Expectimax · Game AI · JavaScript**

### 🚕 [RideFlow](https://github.com/fizzahussain/RideFlow)
A database-driven ride-hailing application covering rider, driver, and admin workflows, with payments, ratings, analytics, and advanced SQL features.

**JavaScript · Express · EJS · MySQL · SQL**

### 💰 [Personal Finance Management System](https://github.com/fizzahussain/Personal-Finance-Management-System)
A personal finance application for tracking transactions, budgets, categories, and financial reports, with a FastAPI backend and Streamlit interface.

**Python · FastAPI · Streamlit · SQLite**

### 🎬 [MoviesData Manager](https://github.com/fizzahussain/MoviesData-MANAGER)

**C++ · AVL Trees · Hash Tables · Graphs · BFS**
